Open Office files in Google Workspace.

Excel, Word, PowerPoint and CSV files can be opened in Google editors. This guide explains the safest workflow, what converts well, and what to check afterwards.

Which Google editor should you use?

Use Google Sheets for XLSX, XLS and CSV spreadsheets. Use Google Docs for DOCX and DOC documents. Use Google Slides for PPTX and PPT presentations. Selecting the matching editor helps preserve the structure Google can import.

Option 1: upload through Google Drive

The traditional method is to open Drive, select New, choose File upload, wait for the upload, and then open the file. This is useful when you need to select a specific folder or upload many files together. It also gives you time to review the destination before conversion.

Option 2: use SheetLaunch

  1. Install SheetLaunch and sign in with Google.
  2. Find the downloaded Office or CSV file in Windows Explorer.
  3. Right-click it and choose Open with, then SheetLaunch.
  4. Wait for the conversion modal to finish and continue in the browser.

The original local file is not renamed or overwritten. The converted copy is stored in your connected Google Drive account.

What may change during conversion?

Basic text, tables, worksheets, common formulas, images, lists, and ordinary formatting often transfer well. Review important files for page breaks, fonts, charts, formulas, slide alignment, comments, tracked changes, embedded objects, and external links. Excel macros and VBA do not become Google Sheets scripts automatically, and unusual Office add-ins may not work in a browser editor.

How to avoid duplicate copies

If you open the same local file repeatedly, enable SheetLaunch file reuse. The app can remember a local fingerprint and the Drive copy so a later open returns to the existing document. If you intentionally want a fresh conversion, turn that preference off or use a different source file.

Privacy and permissions

Conversion requires Google sign-in and an internet connection because the selected file must reach Google Drive. The Drive account you connect controls ownership, sharing, and deletion. Keep sensitive files in the correct account and check sharing permissions before sending a converted copy to other people.

Troubleshooting

If SheetLaunch is missing from Open with, choose Windows’ Choose another app option and select the installed application. If a file fails, confirm the download completed and the extension is supported. Do not rename an XLSX to DOCX or change an extension to force a different editor. For complex files, test a copy first and compare the result with the original.
