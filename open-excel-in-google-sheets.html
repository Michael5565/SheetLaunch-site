How it works

Install SheetLaunch, sign in with Google, then right-click an Excel file and choose SheetLaunch from Open with. The file is uploaded directly to your Google Drive and opened as an editable Google Sheets copy in your default web browser.

Opening Excel files step by step

SheetLaunch is useful when an Excel workbook arrives as an email attachment, download, or shared local file and your daily work happens in Google Workspace. Instead of navigating Google Drive manually, you can start from the file on your desktop.

  1. Install SheetLaunch and connect the Google account that should own the copy.
  2. Locate the XLSX or XLS workbook in Windows Explorer.
  3. Choose Open with and select SheetLaunch.
  4. Wait for the handoff to finish, then review the workbook in Google Sheets.

Can it avoid duplicate files?

Yes. Enable file reuse in SheetLaunch to reopen an existing Google Drive copy when you open the same local file again. You can disable reuse whenever you intentionally need a fresh copy.

What Excel features need checking?

Simple tables, formulas, filters, charts, and ordinary formatting import cleanly into Google Sheets. However, you should inspect complex formulas, VBA macros, pivot tables, external links, and specialized fonts before relying on the converted file. Your original Excel file remains unchanged as a backup.

Common issues & troubleshooting

If SheetLaunch is not listed, use Windows "Choose another app" to locate the installed executable. If conversion fails, check your internet connection and verify that the file download has completed fully before opening.
