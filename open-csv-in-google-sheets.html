How it works

Install SheetLaunch, sign in with Google, and choose SheetLaunch when opening a CSV file. The file is uploaded to Drive and opened in Google Sheets.

Will it create duplicates?

You can enable file reuse so the same CSV reopens its existing Google Sheets copy.
